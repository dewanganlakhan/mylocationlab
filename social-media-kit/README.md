## Recommended accounts, in order

1. **Facebook Page** — biggest "find my location" consumer audience; pages also rank for brand searches.
2. **X / Twitter** — brand SERP presence, quick tool tips, SEO community.
3. **Pinterest Business** — your guides/glossary content is a perfect fit; pins drive passive traffic for years.
4. **YouTube** — "how to find GPS coordinates on iPhone/Android" searches are large; one short tutorial per tool.
5. **LinkedIn Page** — credibility + article/blog syndication and backlinks.
6. **Instagram** (+ Threads automatically) — visual tips/stories.
7. **Product Hunt** — one-time launch using the gallery + logo assets.
8. Optional later: **TikTok** (short location tips), **Reddit** (participate honestly in r/androidapps, r/applehelp… — don't self-promo), **Bluesky** (reuse X assets).

After creating profiles, add their URLs to your WebSite/Organization schema `sameAs`
array in `src/layouts/BaseLayout.astro` so search engines link the profiles to the site.

## Regenerating / customizing

```sh
npm run social
```

Edit the `BRAND` object at the top of `scripts/generate-social-images.mjs` to change the
domain, colors, or name, then re-run — every asset rebuilds in a few seconds.

> **Note:** assets were generated with `domain: 'mylocationlab.com'` (matches
> `astro.config.mjs`). If the live domain differs, update `BRAND.domain` and re-run.

Fonts: Plus Jakarta Sans and Inter are bundled in `scripts/social-fonts/` — both are
SIL Open Font License, safe to keep in the repo.
